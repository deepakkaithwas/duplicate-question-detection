# Data Directory

The Quora Question Pairs dataset is not included in this repository due to size and licensing restrictions.

Please download the dataset from Kaggle:

https://www.kaggle.com/c/quora-question-pairs

Place the downloaded training file here:

```text
data/raw/train.csv
```

Recommended structure:

```text
data/
├── README.md
└── raw/
    └── train.csv
```
